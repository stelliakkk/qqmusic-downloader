# v2.1 代码审查与验收

- 队列在 GUI 线程管理，每次只有一个下载任务；搜索和音质查询可以与下载同时运行。登录失效会暂停队列，普通失败只影响当前任务。审查覆盖取消、关闭、重启恢复和单项重试。
- 去重使用歌曲 MID 和实际音质，检查路径、格式、文件大小和修改时间。自动模式仍先尝试更高的授权档位。下载过程中使用临时文件，完整解码后才保存；封面和歌词使用独立文件名和非覆盖写入。
- 只允许 HTTPS 的 QQ 音乐歌单地址及受限重定向，不携带登录凭据访问短链。歌单分页最多 500 首。登录文件、历史、下载目录和验收样本不进入构建目录。

自动化回归覆盖 8 项，包括 Qt 勾选、多次搜索加入队列、失败后继续、暂停/取消、登录失效、历史去重、歌单短链跳转范围和安全的本地路径。实网搜索确认《焦虑型依恋》的具体录音，FLAC 和 320 kbps MP3 均完整解码，SHA-256 与 v2.0 的同音质样本一致，并生成了 JPG、LRC 和分类目录；重复请求复用现有文件。公开歌单成功分页导入 223 首，其中两首从界面勾选进入等待队列。

重新生成和刷新二维码已在实网验证；本轮沿用已保存的登录，不包含手机重新扫码确认。短链跳转规则用模拟响应验证；实网歌单使用标准链接。

独立 Windows 便携构建已启动，实际检查了歌曲页、队列页、历史页和保存偏好；最小窗口使用 Qt 测试截图检查。
