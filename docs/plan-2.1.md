# v2.1 实施与验收方案

目标：保留搜索、单曲音质选择、扫码与原始音频校验，在同一窗口加入批量下载工作区。所有新功能沿用 QQ 账号实际可获取的音源。

1. **队列**：搜索结果可勾选和全选，多次搜索可持续加入；单曲与批量走同一顺序队列。批量默认自动选最高可用音质，也可指定固定档位；固定档位不可用时明确提示。显示等待、下载中、完成、已存在、失败及取消，可暂停启动后续任务、取消当前任务、移除待办及重试单项。登录失效时暂停并引导扫码；重启保留队列，未完成任务等用户恢复。
2. **历史与去重**：成功记录含歌曲版本、实际音质、路径和时间，支持打开文件或定位文件；文件缺失时明确显示。默认按歌曲版本与实际音质去重，仅复用仍存在且符合记录的本地文件；不同音质独立记录。下载仍使用临时文件、完整性校验和不覆盖命名。
3. **歌单导入**：支持 QQ 音乐标准歌单链接、可解析的分享短链和歌单 ID，显示歌单名、曲目及加载上限；选择部分或全部加入队列。查询无音源或指定音质不可用时，逐项解释，继续处理其他任务。
4. **附加文件和目录**：可选下载同名封面 `.jpg`、同步歌词 `.lrc`，可选集中保存或按歌手、专辑、歌手/专辑整理。按任务保存设置快照。附加文件失败单独提示，保留已校验音频，不修改音频字节或覆盖现有文件。
5. **界面**：沿用原有浅色与紫色视觉，在搜索区增加歌单入口，工作区内用「歌曲 / 下载队列 / 下载历史」切换，保留右侧单曲选项。批量动作、空状态、选中状态、登录及错误提示就地展示。检查中文长文本、窗口最小尺寸及键盘操作。
6. **审查与验证**：审查队列状态和恢复、历史损坏与重试、歌单重定向、Windows 文件名与权限、取消和登录并发。运行单元及 Qt 交互测试，再用已有登录实测公开歌单与授权曲目，检查实际音质、原始字节和附加文件。构建独立 Windows 便携版，打开应用检查外观。保留 v2.0 和现有下载，当前阶段只交付本地。
