QQ 音乐下载器 2.0.0 · Windows x64 便携版

1. 把 ZIP 完整解压到有写入权限的位置，例如 D:\Apps\QQMusicDownloader。
2. 双击 QQMusicDownloader.exe。首次运行时，点右上角「扫码登录」，用自己的手机 QQ 扫码并确认授权。
3. 搜索歌名或歌手，选中具体歌曲，再从右侧选择可用音质或「自动选最高音质」。
4. 点「下载歌曲」。默认保存在程序旁的 downloads，可用「更改」选择其他目录。

二维码过期可以刷新。程序会尝试续期保存的登录，服务要求重新授权时会再次打开二维码。
请保留 _internal 文件夹。程序初次运行后会创建本机专用的 data，登录数据由 Windows 加密保护。
分享时请发送原始 ZIP，每个人解压自己的副本。

source 文件夹包含对应的项目源码、依赖源码和校验清单。许可证见 LICENSE 和 THIRD_PARTY.md。
